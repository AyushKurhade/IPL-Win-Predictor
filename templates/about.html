About the Project

IPL Match Prediction is a Machine Learning based web application that uses historical IPL match data and current match conditions to estimate the likely winner.

Designed as an engineering machine learning solution, the application processes real-time chasing dynamics during the second innings of a match. Given target score, current score, overs bowled, and wickets fallen, the system estimates the winning probability for both the batting and bowling teams without reliance on hardcoded heuristics.

Technologies Used

Python Flask Pandas NumPy Scikit-learn Joblib HTML5 CSS3 JavaScript Bootstrap 5

The system utilizes Scikit-learn Pipelines combining categorical OneHotEncoder transformers with an ensemble RandomForestClassifier, served through a lightweight Flask RESTful API and responsive Bootstrap 5 interface.

Machine Learning Pipeline

The model is trained using historical IPL match data spanning ball-by-ball records of IPL matches. During training, every ball bowled in a chase situation is modeled with respect to the final match outcome.

Engineered Match Features
  • Batting Team & Bowling Team: Categorical encoding of competing franchises.
  • Host City: Stadium home advantage and local pitch conditions.
  • Runs Left: The remaining runs needed to surpass the target (Target - Current Score).
  • Balls Left: Remaining legal deliveries in the innings (120 - Balls Bowled).
  • Wickets Left: Dismissals available before all-out (10 - Wickets Out).
  • Current Run Rate (CRR): Score accumulated per over bowled.
  • Required Run Rate (RRR): Runs required per over remaining.
